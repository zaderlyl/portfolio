Le projet

Tableau de bord de statistiques d'écoute musicale. Malgré son nom, le projet n'utilise pas l'API Spotify : les écoutes viennent de Last.fm, et les informations sur les morceaux (pochettes, durées, genres) viennent de Deezer.

Une action GitHub se lance toutes les 6 heures : elle récupère les dernières écoutes, complète le catalogue avec les infos Deezer et enregistre l'historique dans Supabase. Le site affiche ensuite les compteurs, les graphiques par jour et les top albums, plus le morceau en cours de lecture en direct.

Une fonction serverless Vercel sert de proxy à Last.fm pour que la clé d'API reste côté serveur.
