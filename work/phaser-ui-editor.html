Le projet

Un équivalent de Figma pensé pour Phaser : un éditeur web pour construire visuellement des écrans d'UI (menus, HUD, popups) et générer le code Phaser correspondant, sans écrire de code.

Le projet est né d'un besoin rencontré en SAÉ : coder une UI à la main dans Phaser impose des allers-retours constants entre créa et dev. Ici, la créa glisse-dépose des composants (panneau, texte, image, bouton, barre de progression) sur un canvas Phaser à la résolution du jeu, avec un aperçu pixel-perfect.

Chaque élément se règle dans un panneau de propriétés. À l'export, l'outil génère une classe Phaser prête à intégrer, avec une API minimale (open / close).
